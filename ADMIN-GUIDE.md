# Website ka content kaise change karein

1. **http://localhost/developer_portfolio/admin/** kholein.
2. Pehli dafa apna password banayein; baad mein isi password se login karein.
3. **Profile & uploads** mein naam, email, phone, social links, photo aur resume change karein.
4. **Home page**, **About**, **Skills**, **Services**, **Experience** ya **Contact page** mein apna content likhein.
5. List wale box mein har line par ek item likhein. Naya item add karne ke liye **Add item** dabayein.
6. **Projects & case studies** mein project edit karein. Neeche **Edit complete case study** se uska detail page change karein. Naya project pehle save karein; phir uska case-study editor aa jayega.
7. **Save changes** dabayein, phir website refresh karein.

**Visible** se entry hide/show karein. Arrow buttons se order change karein. **Show section** se poora section hide/show karein. Home par pehle teen visible projects dikhte hain.

Contact form ke messages **Messages** mein milenge. Sender ke email par click karke reply kar sakte hain.

Yeh changes local XAMPP wali website par apply hote hain.
